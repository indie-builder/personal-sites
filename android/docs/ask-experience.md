# 原生问答与引用交互

## 回答依据

沿用站点 `/api/ask`：服务端检索公开资料、把本轮资料包交给模型，要求按 `【1】` 等编号引用，资料不足时明确说明。Android 不追加模型外知识，也不伪造来源。检索范围可选全部、个人资料、每日动态、每日关注、开源内容；推荐问题会选对应范围。

## 引用

- 完整接收来源的 `id/sourceId/content/scope/section/publishedAt/title/sourceUrl`，保持服务端数组顺序就是引用编号，不静默跳过无效元素导致编号错位。
- 回答里的有效 `【n】` 或 `[n]` 为可点击文本链接；回答下方的编号来源行提供至少48dp的等价入口。无效编号不生成跳转。
- 点击后在当前问答内打开原生引用阅读页：标题、栏目/日期、完整检索资料片段。这里显示的是服务端返回的检索正文，不是重写摘要，也不宣称定位到未经接口提供的句子坐标。
- 不启动浏览器，不调用原文外链。返回恢复对话滚动位置和草稿；打开引用不打断正在生成的回答。
- 正文缺失明确提示，不用网页替代。引用展示不依赖额外网络请求。

## 输入与对话

- 回答使用 CommonMark 解析为原生 Compose：标题、段落、嵌套列表、粗体/斜体/删除线、引用、行内代码、代码块与表格。代码和宽表格局部横向滚动；原始 HTML 仅当普通文字显示，不加载远程图片或执行网页内容。
- 引用在解析后的文本节点中绑定，代码块内的编号不变成引用。复制保留原始 Markdown 便于粘贴到编辑器。回答下方使用18dp复制/重新生成图标，点击区48dp；复制成功显示短暂勾选反馈，读屏标签仍说明完整动作。

- 输入框1–6行自适应，更多内容在框内滚动；软键盘回车换行，硬件 Ctrl/⌘+Enter 发送。
- 问题去除首尾空白后2–1000字符；空白/过短/超长时发送不可用，超限内容不静默截断。
- 生成中仍可编辑下一条草稿，发送按钮切换为停止；资料范围在生成中锁定。发送后收起键盘。
- 推荐问题填入草稿并聚焦，不自动提交。新对话清空当前对话和草稿前确认。
- 跟随最新回复；用户向上阅读时停止跟随，提供“回到最新回复”。不能每个 token 都强行滚到末尾。
- 失败保留部分答案和来源，末尾提供重试。重新生成替换最后一问的回答，不额外复制用户问题，并沿用那一问的范围。
- 复制和原生文字选择可用。离开问答取消生成；在问答内查看引用不取消。

## 流协议与状态

按 SSE 空行分帧，支持多行 data；显式 done 才成功。EOF未完成、协议错误、HTTP失败有独立错误状态。error 后不再补 done。每个请求有代次隔离，停止/新对话后的旧回调不再更新界面。

消息区分生成中、完成、停止、失败，不能把历史失败消息显示成当前“正在思考”。会话与答案保存在当前 App 进程中，草稿使用 Compose saved state；不承诺跨进程恢复历史会话。

## 验证

本地真链路：在仓库根目录构建后启动 `pnpm exec next start --hostname 127.0.0.1 --port 7100`，执行 `adb reverse tcp:7100 tcp:7100`，再在 Android 目录运行 `./gradlew :app:installDebug -PlocalAskPort=7100`。仅调试包的 Ask 指向回环地址，其他公共读取保持原配置。正式包始终使用 HTTPS 站点，不包含此 HTTP 例外或模型凭据。

`./gradlew :app:testDebugUnitTest :app:connectedDebugAndroidTest :app:lintDebug`

单元测试通过 OkHttp 拦截的固定 SSE 响应覆盖协议和引用保真；设备测试使用明确的测试引用，不访问外部网站或消耗模型调用，验证发送校验、引用阅读和草稿返回。真实服务的模型可用性单独报告，不能用测试响应替代线上成功证据。
