# 微信小程序交付记录

日期：2026-10-18。交付范围以 iOS 现有公开内容阅读能力为参考，代码位于 `apps/miniprogram`。这里只记录实际执行结果；微信账号下的审核发布另行验收。

## 已实现

- 七个原生页面：首页、内容/引用详情、问一问、作品集、作品集合、作品详情、关于我。
- 动态的五栏目分页、刷新、失败恢复和栏目状态保留；新闻按 ID 详情，策展与开源复用公开列表投影。
- 文本 SSE 问答、跨数据块中文/表情解码、取消真实请求、旧回调隔离、原始范围重试、新对话确认与有序引用阅读。
- 作品集读取独立项目 API，提供布局参考、灵感集、设计工程工具、个人网站四项能力；搜索、分类、布局主题、分页和原生媒体详情。
- 黑白阅读界面、系统深浅色、原生导航和来源复制出口；只复制现有公开头像，不打包数据库或本地输入。

## 独立评审修复项

独立正确性与界面评审确认首页刷新失败重试模式错误、横屏配置缺失、作品详情连续阅读差距，均已实现对应修复：各栏目重放失败请求模式、全局开启自动方向并增加 Ask resize/键盘回归、在当前作品附近最多 120 件已加载结果内提供上一件/下一件。另修正测试 harness 的原生 tab 缓存生命周期，并验证切 tab 保留会话与草稿、取消隐藏页的流式请求。第二轮独立复核将四项分别判为已解决，结论仅覆盖代码与契约，不覆盖实际平台界面与网络。
