# Domain Docs

采用 single-context：Web、原生客户端与离线内容工具共用根目录领域语言，不按技术工作区拆分术语。

- [GLOSSARY.md](../../GLOSSARY.md)：讨论内容收录、公开投影、检索和问答等领域概念时读取；代码、任务及评审沿用其中的术语。
- [docs/adr/](../adr/)：作出或修改设计决策前，只读相关 ADR。先核对状态与失效说明；已退役功能的历史决策不构成当前实现要求。
- 术语只定义领域含义；实现路径与运行约定查 [工作区说明](../monorepo.md)、[前端架构](../frontend-architecture.md) 和各平台 README。

新术语在含义确认后补入现有术语表，真实取舍在形成决策时记录 ADR。文件缺失时继续当前工作，不为凑齐结构预建文档。若与仍有效的 ADR 冲突，明确说明冲突和重议理由，再按用户决策推进。
