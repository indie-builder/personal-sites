# Triage Labels

| Canonical role | GitHub label | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求明确，可由 Agent 实施 |
| `ready-for-human` | `ready-for-human` | 需要人工参与实施 |
| `wontfix` | `wontfix` | 决定不实施 |

分诊时使用此映射，保留 `bug`、`enhancement` 等现有类别标签。首次使用前核对远端标签；缺失时按任务授权创建，不重命名或覆盖已有标签。
