# 像素助手与角色问答参考

[设计规范入口](../../DESIGN.md)规定全站 token、布局与通用规则；本文件保留对应场景的完整约束。动效实现与清理契约见[前端动效参考](../frontend/motion.md)。

### 像素助手（指定参考的局部例外）

抽屉输入区按参考使用桌面 14px / 手机 16px 字号，初始高度 84px、16px 圆角、18px 外边距；30px 圆形上箭头通过透明扩展保持 44px 点击范围。欢迎角色轨道与欢迎文字的实际行宽对齐，建议图标位于文字左侧。独立 `/ask` 页及其专用工具栏已下线。

助手入口位于左侧身份轨的技术词条下方，从“十余年……”正文第一行左端入场，沿正文行移动。正文打字换行时，通过 220ms 的段落高度过渡平滑推开下文，不预留整段空白；手机与 reduced-motion 保持完整静态正文。角色图形、随机步进、停顿、转身与下沉/升起动作参考 Joey Pescatore 站点的 Ovid。打开后桌面内容面板收窄 420px，右缘以 32px 圆角露出浅灰聊天区，无暗色遮罩；手机聊天区从底部展开。欢迎内容居中、白色建议按钮与底部 16px 圆角输入框使用原参考的轻微阴影。该视觉例外只用于助手，不改变信息流设计。键盘、reduced-motion 与会话恢复继续遵守本站约束。

### 角色问答

- 唯一问答界面是角色打开的抽屉，布局与动效遵循上文「像素助手」规则；旧 `/ask` 路由返回 404，不提供重定向或隐藏的第二套页面。
- 统一检索全部公开资料；旧页面的范围菜单、清空对话、纸飞机发送动画与专用滚动壳均已删除。
- 用户消息为右侧墨泡；Web 助手回答统一使用 OpenUI 官方默认组件库渐进渲染，文字也由其 TextContent 组件呈现，不按问题类型切换渲染器、不维护自定义组件库。结束后显示默认折叠的“参考资料 · N 篇”，点击才展开来源列表；保留停止生成、失败重试和会话草稿恢复。
- OpenUI 使用官方主题接口对齐站点字体（固定 light 模式），默认正文 13px、紧凑标题 14px，来源 12px；组合器 12px 圆角，建议和输入不使用装饰阴影。手机输入仍为 16px，触达尺寸保持 44px。
- 欢迎建议与回答后的一条追问建议直接提交问题，输入框停靠抽屉底部并照顾安全区；手机输入字号 16px。
