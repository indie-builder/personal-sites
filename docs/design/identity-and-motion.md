# 身份轨与动效参考

[设计规范入口](../../DESIGN.md)规定全站 token、布局与通用规则；本文件保留对应场景的完整约束。动效实现与清理契约见[前端动效参考](../frontend/motion.md)。

### 身份轨

- 身份区是全站稳定锚点。桌面呈现头像、姓名、外链、技术信号场与简介；手机首页的介绍在技术词条之前，内容页收敛为紧凑头部。
- 桌面使用 `position: sticky` 与 `100dvh`；详情页必须复用相同身份轨，不能出现第二套侧栏视觉语言。
- GitHub、语雀、作品集、关于我构成身份轨的链接行：quiet 文本 + 图标的同行链接，墨色 hover；均为外链或弹层，站内入口不进身份轨。
- 点描头像首访保留名字序列（陈→远→头像）；此后点击头像在点描头像与像素小伙伴之间切换。指针点击飞成伙伴后进入横向连续冒险：十段小故事（助跑跨栏、一跃过断桥、三级台阶、顶块找线索、推箱搭桥、搭乘升降台、追上移动平台、低头过窄门、弹簧送一程、开门继续走）各约 10 秒，一轮约 100 秒，播完回到第一段无限循环，没有定时自动返回，直到再次点击才从当前位置逐像素回到头像；进行中点击即时反转方向，不排队续播。当前段落以 `data-avatar-chapter`（hurdle/gap/stairs/bump/pushbox/lift/movingplatform/crouch/spring/gate）与 `data-avatar-round`（自 1 起的轮数）只在选中伙伴期间暴露，头像态不出现，且仅在段落边界更新。键盘与减少动态路径的点击直接呈现首段中途的静止可读帧，再次点击回到头像。会话中途开启减少动态时，已选中的伙伴定格为当前段的静止帧并保留选择与段落键，关闭后仅续播指针选中的冒险；开场与返回途中开启则直接回到头像。冒险与头像共用同一透明画布与墨色，随页面底色融合，不另铺纸底。冒险只在头像槽位尺寸内渲染（240 单位场景坐标投影到轨道头像尺寸），该尺寸即阅读尺寸，不放大、不另开画布。切换只由输入触发：不自动轮播，不新增选形控件；冒险时钟只累计可见播放时长，隐藏/离屏时变形与剩余停留一并暂停，静止头像不跑动画帧。

### 技术信号场

- 完整词库保留在代码中，常规动效同屏约显示 12 个节点；词条以固定种子选取，保证 SSR 与 hydration 产出同一份词库。
- 动效形态是从右向左的弹幕：6 条泳道各自只运行一个连续轨道，轨道以两份等宽序列无缝循环并用大间距维持稀疏；词条经过容器两侧时被渐隐遮罩裁切——裁切是弹幕语义的一部分（流动的信号，而非陈列的标签），是已裁决的有意设计，不要当作溢出缺陷修复。
- `prefers-reduced-motion` 的静态终态是 3×4 规则网格：这是登记在册的例外——静态形态优先完整可读，不复刻弹幕；两种形态不要求布局同构。

- 持续滚动在信号场离开视口或文档隐藏时自动暂停；减少动态效果时使用完整可读的静态词条。

- 桌面细指针掠过信号场时，底纹点阵以水波纹径向偏移：波环约 180px/s 外扩、约 1.2s 衰减落定，落定后画布定格回与 CSS 静态点阵等价的格点并停表（无空转 RAF）。波纹只作用于背景点阵，不触碰词条弹幕与视差；触屏、无悬停指针与 `prefers-reduced-motion` 下画布不接管，CSS 静态渐变点阵始终兜底。

### 双语简介

- 桌面首访简介在 Loading 后播放一次：英文标题与正文逐字显示 → 英文正文与标题逐字删除 → 空标题光标闪烁两次 → 中文标题与正文逐字显示。正文稳定为中文后，标题以多语言问候语持续轮换。
- 删除速率快于输入；最终可访问、可复制的正文必须是中文；持续变换的多语言只用于标题问候语。
- 打字机序列不提供跳过或快进：它与 Loading 同属首访仪式，仪式成本只对每个会话的首次到访发生，这是已裁决的设计决定。
- 手机直接呈现完整中文介绍，采用 mobile-bio 字号与 1.65 行高，不播放桌面逐字序列。正文宽度跟随身份区，不保留人为最大宽度造成的右侧空白。

### 关于我打印稿

- 身份区 GitHub、语雀、作品集同一链接行内有一个"关于我"触发器（打印机图标 + 文字按钮），点击后打开全屏弹层（`role="dialog"`、焦点受控）：一台拟物打印机把小票从出纸口**逐段送出**，`clip-path` 配合 `steps()` 制造机械式走纸节奏；**每一行文字在走纸到达时瞬时以全浓度切出**，不做淡入，也没有压线等覆盖物。
- **受控拟物例外**：打印机的渐变机身、噪声纹理与多重阴影是全站唯一登记的拟物/阴影语言——它模拟真实打印的触觉仪式，纯平面规则只在这一台机器上让位；机器之外的任何界面元素不得援引此例外。
- 小票内容为两列网格：时间段+公司贴左列，描述贴右缘，两端对齐；附注行（如 OPT 一人团队）归属描述列并随右缘对齐。
- 小票是白色纸张（`#f8f8f8`）——打印件不随界面换装；顶部虚线撕边、底部 SVG 锯齿边，内容为等宽字体（打印语文义，不属于技术信号场的等宽规则）。
- 打印状态文案在机器屏幕上（"正在打印个人经历…" → "打印完成 · 请取走小票"）；经关闭按钮、背板点击或 Esc 收卷（快速反向动画）。
- `prefers-reduced-motion` 下小票直接完整出现，无走纸动画。

### Loading

- Loading 是根布局的一次性全屏遮罩：电池绿色 + 插画序列，完成后向上揭幕。
- 揭幕（上滑）开始时内容流同步播放「档案摊开」入场：刊头与首批至多 6 个内容单元按 32ms 阶梯做 0.45rem 上浮 + 淡入，总时长约 0.5s，可中断、终态交还 CSS；它与仪式共用同一份 sessionStorage 成本模型——每会话仅一次，回访与切版块都不重播，`prefers-reduced-motion` 下不武装、内容直接呈现；揭幕事件未到达时有兜底恢复，页面绝不留在隐藏态。
- 首访仪式是固定时长的刻意设计：常规模式下 5 秒电池充电序列，不与真实加载进度挂钩，也不提供跳过；`prefers-reduced-motion` 下约 160ms 直接揭幕。每个会话仅播放一次（sessionStorage），回访零成本——这个成本模型本身是已裁决的设计决定，不要再按真实就绪事件改造它。
- 站点仅提供浅色主题（`color-scheme: light`），无主题切换控件；旧版存储的深色偏好不再生效。
- 动效分别服务首访揭幕、身份展示、导航定位、追加反馈和媒体状态。所有动效必须可清理、有稳定终态，并提供减少动态效果路径。

### 动效决策

| 场景 | 行为 | 时长 / 曲线 |
| --- | --- | --- |
| 同级栏目切换、键盘导航 | 立即提交路由，不等待离场 | 无内容位移 |
| 指针按钮按压 | scale(.97)，松开恢复；不作用于长文行 | 120ms，cubic-bezier(.23,1,.32,1) |
| hover 颜色 | 只更新当前控件颜色 | 180ms ease |
| 媒体 hover | 仅精细指针支持轻缩放 | 200ms，ease-out |
| 手机身份展开/收拢 | 保留空间关系，键盘与 reduced-motion 跳过 | 沿用既有可清理桥接 |
| 首访与打印稿 | 保留既有受控身份表达 | 按原有专节，不扩散至高频操作 |

不使用 transition:all。移动/缩放 hover 必须放在 `(hover:hover) and (pointer:fine)` 内。减少动态效果不播放按压缩放、路由位移或图像滑动；状态与操作结果仍即时呈现。弹出菜单从触发位置展开，保留 Radix transform-origin。所有动画完成或卸载后恢复可用终态。

手机阅读列表的身份收拢保留 sticky `top` 的 240ms 状态过渡，作为布局属性例外；负停靠位置在中段滚动与上滚迟滞区受自然位置约束，直接换成 transform 会改变导航位置。

2026-09-09 调整：按用户要求移除技术词条的手动暂停按钮；保留正常滚动、屏外自动暂停与系统减少动态效果路径。
