# 作品集整合

个人站是唯一 Web 应用与部署入口。首页身份轨的「作品集」链接进入 `/portfolio`；作品时间轴保留自己的展示节奏，作品详情在同域名内完成。站点的策展阅读流与作品集采用同一人的内容和来源规则，不强行合并成一个页面模板。

## 按功能分目录

| 目录 | 职责 |
| --- | --- |
| `app/portfolio/` | 作品时间轴、四类作品页面及分区布局；公开 URL 均以 `/portfolio` 开头 |
| `components/portfolio/` | 时间轴、书架、灵感墙、媒体浏览、导航与主题控件 |
| `lib/portfolio/` | 作品注册表、筛选、浏览上下文、动效与链接工具 |
| `packages/layout-compositions/` | 350 条图鉴、纠错映射与图片同步 |
| `packages/inspora/` | 灵感集 SQLite、两路来源抓取与公开媒体同步 |
| `packages/design-engineer-tools/` | 工具目录与图标同步 |
| `packages/personal-sites/` | 本站在作品时间轴中的公开介绍、样张与宣传片生成素材 |
| `public/{layout-compositions,inspora,design-engineer-tools,personal-sites}/` | 已公开且可直接服务的媒体 |
| `app/api/portfolio/` | Web 与客户端共用的公开只读 API |

`packages/` 继续保留内容来源边界，因为它们有独立同步命令和数据生命周期；不再保留第二个 `apps/web`、第二套 Next 配置和第二次部署。页面样式限定在作品集布局之内，现有身份轨与阅读流不套用作品集网格。

## 页面与视觉关系

1. 个人站首页仍优先说明“陈远是谁、持续关注什么”。作品集是身份轨中的站内入口，不挤占每日阅读栏目的位置。
2. `/portfolio` 展示按上线日期排序的作品时间轴；每个作品只有一个主要入口。布局参考、灵感集和工具目录按原有交互保留搜索与来源出口。
3. 作品集内页的返回目标是时间轴或当前集合，跨回个人站通过作品集页的「返回个人站」入口完成。指针往返在目标内容挂载后使用镜像的短距离入场；键盘与减少动态效果即时切换。桌面与手机都使用同一路由。
4. 作品集保持中性双主题与 Albert Sans；个人站正文仍按 `DESIGN.md` 的身份轨规范。主题变量只作用于作品集根节点，避免污染原有页面。
5. 所有作品、截图、工具及来源均使用现有真实公开资料。私有资料目录不会成为作品集或 API 的运行时回退源。

## 四条内容路径

| 入口 | 浏览行为 | 内容与同步边界 |
| --- | --- | --- |
| 布局参考 | 八本分类书进入双页画册；可按分类、主题、关键词定位，图片放大即详情，缺图条目仍可浏览 | `catalog.json` 与 `corrections.json` 是稳定图鉴索引；同步脚本生成本地缩略图，高清图优先本地，否则访问上游 CDN |
| 灵感集 | 24 件起始的图片与视频网格；中文分类、即时搜索、滚动追加；详情可看作者与原作，返回保留筛选和位置 | `inspora.db` 保存两路来源的公开内容并按原作去重；本地保存海报、缩略图与头像，大图和视频按来源 URL 播放 |
| 设计工程工具 | 分类平铺的工具目录；工具链接打开原站 | 同步脚本更新公开工具目录和 favicon，不抓取目标工具页面正文 |
| 个人网站 | 本站的作品介绍与真实宣传片；主出口返回个人站首页 | 公开样张和宣传片素材与当前站点同仓库维护，不从私有个人资料生成页面 |

共同规则：作品时间轴按已有日期排序；未确认上线日期的作品明确标成收录日期。集合详情只显示公开作品信息、作者、分类和原作链接，不展示原始 JSON、抓取状态或内部文件字段。横向浏览、翻页、灯箱、返回与主题切换均保留键盘、触摸、焦点恢复和减少动态效果路径。手机保留同一内容和可操作入口，避免横向页面溢出。

## 同步和退役

四条 `portfolio:sync:*` 命令都在本仓库根目录执行，生成物落在本仓库的 `packages/` 与 `public/`。只迁入功能代码、已公开内容、可再生的媒体和宣传片素材；旧项目中的 `.agents/`、历史评审、构建缓存与本机状态不参与运行。部署并验证 `/portfolio`、四类详情、`/api/portfolio` 和媒体后，再将旧域名设为跳转并停用旧仓库的自动同步；旧仓库可留作只读归档。
