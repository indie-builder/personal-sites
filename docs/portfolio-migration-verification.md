# 作品集合并验证记录

## 范围

以主站 `1cc0fa7` 和作品集 `3c6837370fccadb18a870227bcc95c8f74de3d62` 为基线，将七个作品、公开 API、媒体、维护工具和原生调用方迁入一个 Web 应用。源仓库只读，未修改旧部署、DNS 或仓库归档状态。

## 实现决策

采用既有 Web、public-data、content 分工，复用作品组件与 `/products/*` 路由。作品首页使用纵向条目及站内模式切换。保留独立作品聊天，未将其协议或历史并入 Ask。小型公开目录保留 JSON，灵感集使用根 `data/portfolio.sqlite`。

两份架构候选由单一配置模型生成，独立 Opus 评审选择现有所有权方案。数据与集成评审发现的分类相邻导航、发布失败保留、表单校验、主题、词典定位、聊天可见高度和画册宽度切换问题均已修复。最终针对性独立复核未发现剩余高、中等级阻塞。

## 数据和资源证据

- 公开灵感投影保留 9,703 个可见作品与 13,025 个有序媒体项，227 个轻量视频预览保持一致。
- 独立只读对照确认作品 id、slug、分类、顺序、媒体地址及尺寸一致。494 个被投影选中的本地媒体路径均存在。
- 1,050 个迁入的公开文件与源项目逐字节摘要一致。保留词典冻结运行资源和公开宣传片。
- 数据库不含原始载荷、内部来源、去重专用 tweet id 和媒体体积字段。工具公开目录去除同步时间与来源站点元数据。
- 11 组公开 API 对照涵盖索引、搜索、末页、工具、网站介绍、非法分页和缺失详情。归一化站点地址及媒体版本参数后全部一致。
- 最终生产构建的 41 份文件追踪无缺失文件，无敏感目录、Smaug 或原作品集 checkout 路径。最大单份追踪文件总大小约 85 MB；此值是本机构建文件统计，不是平台部署额度的实测。
