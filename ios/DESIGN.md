# iOS 作品集设计记录

## Overview
范围仅限 `UI/PortfolioView.swift` 的原生作品集；不覆盖网站设计规范，也不扩展为组件库。
首页四行展示布局参考、灵感集、设计工程工具、个人网站，点击进入原生页面。
依据当前代码与 `/tmp/portfolio-redesign/` 下 home、layouts、detail、muse、tools、site 截图；已核对末次更新的详情、工具和网站介绍截图。

## Colors
复用 `SiteTheme`：浅色背景白色、正文近黑、辅助文字灰色、浅灰分隔；暗色值由现有主题提供。
图像保留原作颜色，界面不另加大面积强调色。

## Typography
沿用当前固定字号系统字体：页标题 22pt 半粗，首页作品名 18pt 半粗，列表标题 15pt medium，正文 15pt，标签 14pt medium，元信息 12pt。
本次不扩展 Dynamic Type，也不另建字体系统；工具名最多两行，左对齐。

## Layout
首页左右边距 24pt；行内图文间距 20pt、上下内边距 20pt，右侧封面 100 × 112pt；布局参考封面额外内缩 8pt。
集合页左右边距 20pt；搜索框高 44pt、水平内边距 12pt；分类操作至少高 48pt。
集合网格为 adaptive 最小列宽 145pt，列距 14pt、行距 24pt；布局封面宽高比 0.72，灵感封面 1.25。
详情左右边距 20pt，媒体按来源宽高比展示，媒体底部间距 12pt；正文前距 20pt，底部前后项操作至少高 48pt。
工具页左右边距 24pt，两等宽列、列距 20pt、行距 6pt；分类间距 24pt，分类标题与内容间距 14pt。
工具图标 24 × 24pt，图文间距 10pt，条目至少高 52pt；个人网站视频宽高比 16:9。

## Elevation & Depth
内容主要靠留白、图像和细分隔线组织，不增加卡片阴影；底部导航继续使用应用既有样式。

## Shapes
封面、详情媒体和视频圆角 8pt，搜索框圆角 10pt；播放按钮使用圆形。

## Components
首页和集合读取现有公开作品集 API；保留索引契约、服务端总数、搜索筛选和分页，不为视觉改版改造 API。
图片、视频、作者和原作链接来自服务返回；布局缩略图完整适配，灵感缩略图按预览区域裁切，详情保持媒体比例。
缺图显示明确占位，不生成替代作品；布局详情保留来源及 CC BY 4.0 标注。
详情使用原生全屏阅读器，完成后返回集合；上一件、下一件仅遍历当前已加载项。
底部显示“第 N 件”，不把已加载项数当总量；最终 detail 截图已确认显示“第 1 件”。
工具条目打开 API 提供的工具官网外部地址；网站介绍保留视频及打开网站入口。
最终 tools 截图已确认无尾部箭头，SearchSystem 单行完整展示，Game UI Database 等长名称自然换行；site 截图可见视频预览、介绍和打开网站入口。

## Do's and Don'ts
保持简单个人应用：真实内容、四行首页、原生集合与详情、直接官网入口。
不新增 mock、独立设计库、装饰性功能或虚构的已验证结论。

## 布局参考分类书架
布局参考默认入口展示全部 8 个分类，两层书架、每层 4 本；每本书显示分类名、顺序和 API 返回的图鉴数量。
书脊沿用原网站 8 色（赤陶、亚麻、青灰、赭黄、蓝、锈红、橄榄、象牙），仅用于分类书籍。左右边距 24pt，书间距 10pt，高度 182–204pt；固定中文竖排与底部数量。
点书进入分类图鉴，支持主题筛选、搜索和详情；“书架”清空筛选并返回全部分类。“浏览全部图鉴”直接打开完整集合；书架搜索跨全部分类。
不添加翻书动画或新数据接口；分类、数量和图鉴继续读取现有公开 API。
